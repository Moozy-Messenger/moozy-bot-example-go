# Moozy Bot Example — Go

Простой **Echo-бот для Moozy Messenger**, написанный на Go без сторонних библиотек. Пример показывает, как подключиться к [Moozy Bot API](https://core.moozy.org), получать сообщения и отправлять ответы.

> Это учебный пример, а не готовая платформа для высоконагруженных ботов.

## Возможности

- `/start` — приветственное сообщение.
- `/help` — краткая справка.
- Любое другое текстовое сообщение — ответ вида `Echo: ваше сообщение`.
- Проверка токена бота через `getMe` при запуске.
- Получение новых сообщений с помощью `getUpdates`.

## Требования

- **Go 1.22** или новее.
- Созданный бот Moozy и его токен вида `mzb_...`.
- Пользователь должен первым открыть диалог и начать общение с ботом.

Скачать Go: https://go.dev/dl/

## Установка и запуск

Склонируйте репозиторий:

```bash
git clone https://github.com/Moozy-Messenger/moozy-bot-example-go.git
cd moozy-bot-example-go
```

**Windows (PowerShell):**

```powershell
$env:MOOZY_BOT_TOKEN="mzb_ВАШ_ТОКЕН"
go run .
```

**Linux / macOS:**

```bash
export MOOZY_BOT_TOKEN="mzb_ВАШ_ТОКЕН"
go run .
```

Оставьте терминал открытым. В Moozy найдите своего бота, начните с ним диалог и отправьте `/start`, `/help` или любой текст. Для остановки нажмите **Ctrl + C**.

## Используемые методы API

| Метод | HTTP | Назначение |
| --- | --- | --- |
| [`/bot/getMe`](https://core.moozy.org) | GET | Проверка токена и получение сведений о боте |
| `/bot/getUpdates?limit=20` | GET | Получение новых событий |
| `/bot/sendMessage` | POST | Отправка текстового ответа |

**Базовый адрес:** `https://v1.moozy.org`  
**Авторизация:** `Authorization: Bearer <BOT_TOKEN>`

Пример запроса:

```bash
curl https://v1.moozy.org/bot/getMe \
  -H "Authorization: Bearer $MOOZY_BOT_TOKEN"
```

Полная документация: **https://core.moozy.org**.

## Важные ограничения

- В текущей реализации Moozy API `getUpdates` **сразу помечает возвращённые обновления как доставленные**. Если обработка прервётся, обновления могут быть потеряны; подтверждения по `offset` и long polling пока нет.
- **Не запускайте два экземпляра бота одновременно.** Если включён webhook, `getUpdates` может вернуть HTTP 409. Перед запуском polling отключите webhook.
- `chat_id` для ответа берётся из полученного события и соответствует ID пользователя. Бот не может писать пользователю, который не начал диалог или заблокировал бота.
- Пример намеренно не повторяет неудачные отправки автоматически, чтобы не создавать дубли сообщений.

## Безопасность

**Никогда не публикуйте токен бота** в GitHub, скриншотах или сообщениях. Передавайте его через переменную окружения `MOOZY_BOT_TOKEN`. Если токен оказался раскрыт, отзовите его и создайте новый.
